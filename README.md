# SirenAI Bot & Control Dashboard

開発者向けの管理・投稿システムです。AI（Gemini）を利用して、ユーザーにはシステム感を感じさせない自然な投稿を自動生成します。

## プロジェクト構成
- `/` : ボット本体（Node.js / GitHub Actions）
- `/lib` : AI生成ロジック、テンプレート、コンテンツ取得
- `/dashboard` : 管理画面（React / Vite）

## 使い方

### 1. 自動投稿（放置でOK）
GitHub Actionsにより、日本時間の **1時、9時、17時** に自動投稿されます。
- 設定は GitHub リポジトリの `Settings > Secrets > Actions` で管理しています。

### 2. 管理画面の起動
ボットの状態確認や手動投稿を行うには、PCで以下を実行してください。
```bash
cd dashboard
npm run dev
```
起動後、ブラウザで `http://localhost:5173` を開きます。

### 3. 設定変更
- **X投稿文のトーン**: `lib/ai.js` のプロンプトを編集することで自由に変えられます。
- **テンプレート**: `lib/templates.js` にベースとなる文章を追加できます。

## 注意事項
- このボットは安全性を考慮し、投稿の間に10〜20分のランダムな待ち時間を設けています。
- アカウント凍結対策のため、直接的なURLの投稿は控え、プロフィールへ誘導する形式をとっています。
